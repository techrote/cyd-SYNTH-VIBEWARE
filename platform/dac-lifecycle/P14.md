# P14 — opt-in clock sink and two actual front-panel sessions [Draft/HOLD]

Original portable C++17 platform candidate, not a physical DAC driver. No external source copied. Prior P10 legacy DMA counterexamples and P11 timer review remain binding. Ecophon M4 is a separate PORT-owned candidate, not silently replaced. Same-core serialized producer and non-reentrant interrupt consumer mandatory; reset never called from another task/core. Fixed 512 encoded samples, 128 per publication, 256 required before explicit start. Invalidate inhibits before requesting interrupt-owned discard. Starvation returns midpoint and latches fault until explicit reset/acknowledge/reprime/start; partial or stale-generation submissions are refused by the producer contract (push accepts exactly one complete block, no generation token supplied by external callers). Inhibit/flush does not establish analog silence. Tick is constant work; actual target code generation/IRAM and ISR timing unverified. Do not wrap this in legacy I2S DMA.
