The existing target adapter draws all 240 rows even when nothing visible changes. This experiment uses the exact M4 renderer's six nonoverlapping bands (scene selector, four tracks, transport footer). A completed snapshot is retained, the next snapshot is compared field-by-field, and only potentially changed bands are drawn. No hashes/collision risk, no framebuffer, no change to raster/DSP or audio control. Four rows maximum per synchronous submission; no mid-frame snapshot replacement, no unbounded loop in step. External drawing, display reset/loss, or interrupted transfer must invalidate; the following frame then repaints all rows. A rejected sink retains cursor.
