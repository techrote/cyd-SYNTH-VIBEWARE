M1's single-threaded direct touch interface is now wrapped in a local C++17 runtime: 32 usable SPSC contacts, emergency flag outside the queue, bounded drain, timestamped contact lease and latest coherent Engine snapshot via three owned slots. One input producer, one audio consumer/publisher, one visual reader. No lock, allocation or I/O in Runtime::render. Startup muted; deliberate scene touch starts. Drag-to-panic, invalid input, queue overflow, cancelled or expired held contact silence newly generated PCM; explicit physical release then scene touch to restart. Refused release must be retried after fault acknowledgement. An already generated or submitted audio block is not retroactively removed. Normal release leaves autonomous drone playing. Snapshot readers may skip intermediate frames; cannot tear or block writer. Memory capture is session-local.
