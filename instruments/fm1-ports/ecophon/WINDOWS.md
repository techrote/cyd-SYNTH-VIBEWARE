# Ecophon M2 Windows evaluator

Draft/HOLD; this is a source candidate pending hosted Windows qualification. Extract the entire owner ZIP once available and run Ecophon.exe. Starts muted. Click one of the four scene buttons to begin. The audio is an autonomous drone; releasing the pointer leaves it playing. The four habitat columns show resource levels and actual living agents (species color, energy radius). Change sharing on the horizontal bar, then drag in the XY surface (right = more fertility, up = more pressure). Capture A/B and Recall A/B save and interpolate environmental intent over four seconds; memory survives scene changes only within the session. Freeze halts organism interactions, not replenishment or audio. Panic (including held drag into red cell) or Escape mutes; after a lost/cancelled held gesture release before selecting a scene again. If a contact cancellation prevents release delivery, one deliberate tap/release clears the inhibited state; then choose the scene again.

Actual PCM is 24 kHz mono, waveOut from the same portable engine, three 128-sample buffers. The backend attempts to reset queued device output on transition to mute; physical output latency and actual Windows audio endpoint remain unmeasured. No audio driver callback or allocation in the core. The Windows display renders actual RGB565 rows, converted to a GDI bitmap, with text labels overlaid; PPMs in the gallery are the unadorned core raster, not Windows screenshots. No pressure, multitouch, hardware, upstream source, or firmware claim.

Ecophon.exe --smoke exercises real Win32 mouse events, actual PCM generation, XY causality, held panic, release and restart, and checks graphical drawing. It deliberately uses a simulated PCM sink, not a physical audio device. The package retains original WAVs, frames, replay and runtime fixtures with source SHA/tree, dependency and checksum receipts. See README.md for M1 provenance and controls, M2.md for executed native evidence. Actual Windows build/extraction results are recorded only by the exact-head CI, not inferred from authoring.
