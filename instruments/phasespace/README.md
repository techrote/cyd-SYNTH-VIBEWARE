# PHASESPACE-001 — paired phase instrument (author candidate)
Touch the field to sound; X selects pitch, Y selects mutual phase-rate coupling and second-harmonic morph. Drag continuously; lifting releases. The plot contains the actual decimated paired oscillator waveforms multiplied by their audible envelope, not a separate attractor. Colors distinguish six factory patches.

Bottom buttons 1–6: Glass, Metal, Soft, Detune, Lock, Flux. Q toggles a Dorian-like quantized scale; M switches Y to ratio detune and coupling depth; R arms gesture looping; X cancels immediately. Tap R, then draw a field gesture and release. Up to 64 XY points are retained at nominal 32 ms UI-clock intervals; the first point is immediate, long gestures retain the initial 64 points, and a gesture with fewer than two points is discarded. The loop repeats with one released control tick between repetitions, retaining continuous oscillator phase. R stops/disarms, a new field touch takes over immediately, patch/Q/M changes can modify a playing loop, and panic/focus loss/mute clear it. The R button highlights while armed or playing and is orange while recording. Timing is UI-clock based, with no unbounded catch-up, not sample-accurate sequencing. A contact beginning on the toolbar never plays a note; a field gesture crossing the toolbar remains a field gesture. Windows mouse simulates a single resistive contact. Escape or lost capture cancels. Native audio uses four 128-sample waveOut buffers at 24 kHz mono; software mute applies to subsequent generated buffers, not already queued hardware audio. Default gain is bounded to ±7800 PCM counts; adjust system volume before audition.

## Reproduce
- Native tests: cmake -S instruments/phasespace -B build/phase; cmake --build build/phase --config Release; ctest --test-dir build/phase -C Release --output-on-failure.
- Create a directory, run phasespace_replay with that directory as its sole argument to generate six actual-core patch WAVs and RGB565-derived PPM snapshots plus a scripted gesture-loop WAV. Same compiler: split-block output must be bit-exact.
- Windows: phasespace.exe opens the actual-core mouse/GDI/waveOut instrument. --smoke exercises a real GDI window and scripted core, deliberately does not open the sound device. No claim of listening or real device output in CI.
- Candidate target compile: pio run -d instruments/phasespace/firmware -e cyd-phasespace. No upload command. Board revision and calibration not physically verified; physical deployment HOLD. Audio starts only on explicit serial 'a'; 'm' or BOOT mute. UI panic is recoverable via new field gesture. No radio, PSRAM or external peripherals assumed.
- Reference hardware facts: Diviner 7b1b37eec6ac126f334a0b008d91135071ea60fa src/hal_cyd.cpp and platformio.ini, HYBRID 7cb5f9e40b6edb66115a342a0fd2a80c3ccd0078 cluster/firmware. Own code is original, no reference source copied; third-party dependency licensing and any future redistribution require review. PlatformIO espressif32 6.10.0, LovyanGFX 1.2.32, XPT2046 v1.4 follow the qualified HYBRID build precedent, not physical certification.

## Engineering limits
LUT-interpolated sine with bounded bidirectional rate modulation, only fundamental and second harmonic explicitly mixed; bounded frequency and DC blocker; spectral alias energy and target timing not yet quantified. Fixed-size SPSC visualization ring drops new points on overflow, never blocks audio. Input lease 120 ms of generated audio; one coherent packed control per block. The serializer is named pack() to avoid the Arduino word(...) macro; native replay includes a macro collision guard. Gesture storage is fixed at 64 XY pairs, UI-owner-only, not serialized to the audio owner. Four-row display slices, no full CYD frame buffer, rendering only UI side. Native replay and author CI are not independent acceptance. Physical DAC startup/transients, touch calibration, runtime heap, DMA underruns and actual coexistence are NOT RUN. Draft/HOLD.
